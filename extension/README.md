# Memoria Web Clipper Extension

This is a Chrome Manifest V3 extension that saves selected text from any webpage into Memoria's browser local storage (`memoria.local.v1`).

## Install (Developer Mode)

1. Open `chrome://extensions`
2. Turn on `Developer mode`
3. Click `Load unpacked`
4. Select this `extension/` folder

## Configure

1. Click the extension icon
2. Set `Memoria URL` to your deployed app URL
   - Example: `https://ashwannasleep.github.io/memoria/`
3. Save settings

## Use

1. Select text on any webpage
2. Right click
3. Click `Save selection to Memoria`
4. Open Memoria and check the `Web Highlights` book
